# Animated icon catalog coverage

This audit covers the 467 icon names present in the Lucide Animated reference snapshot on 27 September 2026. Each reference has a counterpart in at least one supported library. Each library keeps its own native geometry, names and visual style. A counterpart is a semantic match, not a claim that its paths or animation are identical to Lucide.

The catalog contains 1,187 components. Reference coverage and component totals differ: equal animation programs can share a native component; differing programs have separately named variants. Earlier icons without a current reference counterpart remain available.

The machine-readable [coverage data](catalog-coverage.json) records all 467 references, each native source, the actual catalog name, the registry name, the public registry URL, and review notes. Package source paths in that file are relative to the corresponding upstream package. Repository component paths are relative to this repository.

## Naming and native limits

- Existing catalog filenames remain stable. For example, Hugeicons native `arrow-down-02` is installed and searched as `arrow-down`; Phosphor native `caret-down` is `chevron-down`. Use `catalogName` or `registryName` from the coverage data when installing a component. `nativeName` documents the upstream geometry.
- References with identical choreography may share a component, such as Tabler `cog` and `settings`. Different programs receive dedicated variants, such as `git-compare-arrows`, so choosing one reference never silently changes another.
- A missing counterpart stays unavailable in that library. No shape is fabricated by combining unrelated native icons, rotating an icon into an unsupported direction, or adding a modifier that the base library does not provide.
- The reference `delete` is a trash can, so all three libraries use native `trash`. The reference `accessibility` is a moving wheelchair, and `radio` is radio-frequency broadcast; their semantic aliases have been corrected. Previous components remain available for compatibility.
- Tabler omissions include the clapperboard reference named `clap`, the cooking pot, a ground satellite dish, and variants whose inside/outside modifiers or arrow directions have no matching native. For example, the outline catalog’s `refresh` is counterclockwise; it is not presented as the clockwise reference.
- Functional counterparts can retain a different native object style: Phosphor `spray-can` uses `spray-bottle`, a trigger spray bottle rather than an aerosol can. This difference is explicit in the native name and mapping notes.
- Phosphor omissions include the wall air vent, text-size arrows, and numerous modified alarm, bookmark and file variants absent from the regular catalog. Its horizontal Git commit, internal calendar check and internal pin plus are not substituted for explicitly vertical/external reference variants. `fish-simple` is not used for the Ichthys symbol, and `graph` is not used for consecutive route waypoints. Filled regular paths retain their native 256 × 256 geometry; stroke-width customization does not apply to them.

The full table below shows every omission explicitly. Review notes in the JSON explain the selected native shape or the reason no equivalent was retained. These limits apply to the package versions above; a later upstream release may add suitable icons.

## Licenses and animation behavior

Native geometries come from the three MIT-licensed packages listed above. Their exact notices are preserved in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) and at the top of every newly distributed TSX component. Copying code or installing a registry item retains that component notice. The animation programs are adapted from the MIT-licensed Lucide Animated source snapshot. Native SVG geometry is retained. See [animation parity and declared limitations](ANIMATION_PARITY.md) for the exact source revision, engine version, adaptations and verification.

Components support pointer and keyboard previews, imperative `startAnimation` / `stopAnimation`, and reduced motion. Playback follows the reference: finite animations may hold their final pose, loops continue until stopped, and reset transitions follow the source program.

Run `pnpm run check-catalog-coverage` to validate these 467 references against the source catalog, searchable aliases, registry outputs and upstream version notices. This check reads metadata and TypeScript syntax without importing the animated React components.
